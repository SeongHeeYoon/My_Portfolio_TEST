# 윤희성 · 포트폴리오 랜딩 페이지

보는 사람이 면접관이 되는 **면접실 연출**로 시작하는 한 장짜리 사이트입니다.

1. 첫 화면에는 문 하나와 `문을 클릭하세요!` 문구가 있습니다.
2. 문을 누르면 좌측 상단에 `들어오세요` 말풍선이 뜨고, 정장 차림의 캐릭터가 걸어 나옵니다.
   문이 닫히며 사라진 뒤 앞에 의자가 생깁니다.
3. 캐릭터가 의자 옆으로 걸어가 인사하고 말풍선으로 자기소개를 합니다.
4. 좌측 상단에 면접관의 `앉으세요` 말풍선이 뜨면 캐릭터가 의자에 앉습니다.
5. 카메라가 책상으로 내려갔다가, 이력서가 올라오면서 함께 올라갑니다. 뒤는 흐려집니다.
6. 옆의 포스트잇으로 이력서 / 자기소개서 / 포트폴리오를 고릅니다. 포트폴리오는 태블릿으로 보여줍니다.
7. 자기소개서를 누르면 면접관이 `자기소개 시작하세요` 라고 말하고, 캐릭터와 눈을 마주친 뒤
   화면 가운데 말풍선으로 자기소개를 시작합니다. 뒤는 흐려집니다.

자기소개 말풍선에서는 큰 제목이 한 글자씩, 문단이 한 번에 나옵니다.
누르면 연출을 건너뛰고, 다시 누르면 다음 문단으로 넘어갑니다. (`스페이스` · `→` 키도 같고, `←` 는 이전 문단)
우측 하단의 이력서 / 포트폴리오 포스트잇으로 다른 문서로 넘어갈 수 있습니다.
문단은 `data.js` 의 `cover` 본문에서 빈 줄로 나뉜 단위이고, 수정 모드와 PDF 에서는 글 전체가 종이에 나옵니다.

연출은 오른쪽 위 `건너뛰기` 로 언제든 넘길 수 있고, `처음부터 보기` 로 다시 볼 수 있습니다.
기기에서 '동작 줄이기'를 켠 사용자에게는 문을 누르면 곧바로 이력서가 보입니다.

## 연출 수정하기

| 고치고 싶은 것 | 위치 |
|---|---|
| 문 안내 · 인사 · 면접관 문구 (`들어오세요`, `앉으세요`, `자기소개 시작하세요`) | `data.js` 의 `intro` |
| 연출 순서와 시간 | `interview.js` 의 `play()` (1000 = 1초) |
| 캐릭터 얼굴 · 옷 | `interview.js` 위쪽의 `characterSVG` (코드로 그린 그림) |
| 방 · 책상 · 종이 · 태블릿 · 포스트잇 모양 | `interview.css` |

## 디자인

힐링 게임 '동물의 숲' 을 모티브로 한 **마을 게시판** 스타일입니다.

- 은은한 크림빛 바탕 + 아주 옅은 점무늬
- 둥근 패널 + 아래로 떨어지는 '스티커 그림자'
- 연한 세이지 초록(버튼·활성 탭) / 부드러운 갈색(하단 배너) / 살구빛(편집 중)
- 구분선은 실선 대신 점선
- 전체적으로 채도를 낮춰 눈이 편한 톤으로 맞췄습니다

색을 바꾸고 싶으면 `index.html` 위쪽 `:root { }` 안의 값만 고치면 전체에 적용됩니다.

## 그림 파일

| 파일 | 쓰이는 곳 | 크기 |
|---|---|---|
| `images/hero-character.png` | (지금은 쓰지 않음) 예전 메인 화면 캐릭터 | 480×499 |
| `images/leaf-icon.png` | 작은 라벨(WORK STEP 등) 앞 아이콘 | 80×80 (20px 로 표시) |
| `images/section-icon.png` | 메인 소제목 왼쪽 두루마리 | 44×44 (44px 로 표시) |
| `images/highnum-cover.png` | 대표 프로젝트 블럭 박스 그림 | 1000×800 |
| `images/profile.jpg` | 이력서 프로필 사진 | 자유 |

세 아이콘 모두 **배경이 투명한 PNG** 입니다.
배경이 있는 그림을 그대로 넣으면 크림색 패널 위에 네모가 생깁니다.

표시 크기의 **2배 해상도**로 저장해 고해상도 화면(레티나)에서도 또렷하게 보입니다.
새 그림으로 바꿀 때도 표시 크기의 2배쯤으로 만들어 넣으면 가장 깔끔합니다.
파일이 없으면 캐릭터는 자동으로 빠지고 나머지 화면은 그대로 나옵니다.

`images` 폴더의 파일들은 원본 그림에서 배경을 투명하게 빼고 크기·용량을 정리한 것입니다.
나중에 다시 다듬으려면 원본 그림이 필요하니, 원본은 따로 보관해 두세요.

## 소제목 아이콘 (두루마리)

포트폴리오의 소제목(Work Step / Game Tournament) 왼쪽에 픽셀 두루마리 아이콘이 붙습니다.

- 지금은 `images/section-icon.png` 를 씁니다.
  원본 `Quest_icon.png` (1254px, 배경 검정) 에서 **검정 배경을 투명하게 뚫고**
  픽셀 격자를 되살려 44×44 로 정리한 파일입니다. (4.7KB)
- **다른 그림으로 바꾸려면** `images/section-icon.png` 를 덮어쓰기만 하면 됩니다.
  정사각형 + 배경 투명 PNG 를 권장합니다. 크기는 44×44 가 가장 또렷합니다.
- 이 파일이 없으면 **코드로 그린 대체 아이콘**이 자동으로 나옵니다.
  `index.html` 의 `ICON_GRID` 가 그 그림이고, 한 글자가 한 픽셀,
  `ICON_COLORS` 가 글자별 색입니다. 글자를 바꾸면 그림이 바뀝니다.

> 배경이 검정인 PNG 를 그대로 넣으면 크림색 패널 위에 검은 사각형이 생깁니다.
> 반드시 배경이 투명한 PNG 를 넣어주세요.
- 다른 페이지의 소제목에도 붙이고 싶으면 `index.html` 에서 해당 `section(...)` 호출의
  마지막 인자를 `true` 로 바꾸면 됩니다.

## 내용 수정하는 법

1. `data.js` 를 메모장·VS Code·GitHub 웹 편집기 아무거나로 엽니다.
2. 따옴표 `" "` 안의 글자만 바꿉니다.
3. 저장하고 브라우저에서 새로고침하면 끝입니다.

규칙은 세 가지뿐입니다.

- 줄 끝의 쉼표 `,` 는 지우지 않습니다.
- 항목을 늘리려면 `{ ... }` 블록을 통째로 복사해 아래에 붙여넣고 쉼표로 잇습니다.
- 줄바꿈이 필요하면 글자 사이에 `\n` 을 넣습니다.

## 프로필 사진 넣기

`images` 폴더에 사진을 넣고, `data.js` 의 `photo` 를 그 파일 이름으로 맞춰주세요.

```js
photo: "images/profile.jpg",
```

경로가 비어 있거나 파일이 없으면 따뜻한 그라데이션 카드가 대신 보입니다.

## GitHub Pages 로 올리기

1. GitHub 에서 새 저장소를 만듭니다 (Public).
2. 이 폴더의 **모든 파일**을 그대로 업로드합니다. (`fonts` 폴더 포함)
3. 저장소 → **Settings → Pages** 로 이동합니다.
4. *Source* 를 **Deploy from a branch**, *Branch* 를 **main / (root)** 로 두고 저장합니다.
5. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 으로 접속됩니다.

> 저장소 이름을 `아이디.github.io` 로 만들면 주소가 `https://아이디.github.io/` 로 짧아집니다.

이후에는 GitHub 웹에서 `data.js` 를 직접 수정하고 **Commit changes** 만 눌러도 사이트가 갱신됩니다.

## 프로젝트 블럭 박스 + 소개 창

태블릿 속 프로젝트 목록은 `data.js` 의 `portfolio` 로 만들어지고, 소개 창도 태블릿 화면 안에서 열립니다.

| 넣은 항목 | 나오는 모습 |
|---|---|
| `cover` 만 없음 | 지금까지처럼 제목 + 설명 글자 카드 |
| `cover` 있음 | 그림이 위, 문구가 아래인 **블럭형 박스** |
| `detail` 있음 | 박스를 누르면 **소개 창**이 열림 |

`detail` 은 소개 창의 내용입니다.

```js
detail: [
  { title: "프로젝트 소개", body: "" },
  { title: "담당 작업",     body: "" },
  { title: "게임 출시",     body: "" },
],
```

- `title` 들이 소개 창 **왼쪽 목차**가 되고, 누르면 그 항목의 `body` 가 오른쪽에 나옵니다.
- 목차는 개수 제한이 없습니다. `{ }` 블록을 늘리면 항목이 늘어납니다.
- 넓은 화면에서는 왼쪽 세로 목차, 좁은 화면에서는 위쪽 가로 탭으로 바뀝니다.
- 닫기: 오른쪽 위 ✕, 바깥쪽 클릭, `Esc` 키
- `body` 가 비어 있으면 '내용 준비 중' 안내가 나옵니다.
  본문은 자기소개서와 똑같이 빈 줄로 문단을 나누고 `**문장**` 으로 강조할 수 있습니다.
- **수정 모드로 로그인하면 이 창 안에서 바로 내용을 입력**할 수 있습니다.
  (그림을 눌러 창을 연 뒤 점선 칸에 입력 → `이 브라우저에 저장` 또는 `data.js 내려받기`)

### 소개 창 본문에 넣을 수 있는 것

`detail` 의 `body` 에 아래 표시를 쓰면 글자 외에 영상·이미지·링크도 넣을 수 있습니다.
각 표시는 한 줄(문단) 맨 앞에 씁니다.

| 표시 | 결과 |
|---|---|
| `**문장**` | 굵게 + 형광펜 강조 |
| `@video 유튜브주소` | 영상 재생 창 (16:9) |
| `@image images/파일.png` | 그림 |
| `@link 주소 \| 버튼글자` | 눌러서 이동하는 버튼 (여러 줄 나열 가능) |

문단은 빈 줄로 나눕니다. 편집 모드에서는 이 표시들이 '글자 그대로' 보여서 바로 고칠 수 있습니다.

## 자기소개서 하이라이트

소제목이 위, 내용이 아래로 오는 세로 구성입니다. 소제목은 굵은 글씨(700)입니다.

꼭 읽었으면 하는 문장은 **굵게 + 연한 형광펜**으로 표시됩니다.
`data.js` 의 `cover` 본문에서 그 문장을 `**` 두 개로 감싸면 됩니다.

```
"...평범한 문장입니다. **여기가 강조됩니다.** 다시 평범한 문장입니다."
```

- `**` 를 지우면 강조가 풀립니다.
- 웹페이지 수정 기능으로 편집해도 `**` 표시는 그대로 유지됩니다.
- 별표 하나(`*`)나 짝이 안 맞는 `**` 는 그냥 글자로 나옵니다.

## 웹페이지에서 바로 수정하기

책상 화면 우측 상단의 **수정** 버튼 → ID / 비밀번호 입력 → 점선으로 표시된 글자를 눌러 바로 고칩니다.
ID 와 비밀번호는 `data.js` 의 `auth` 에서 바꿀 수 있습니다.

> ⚠️ **비밀번호는 안전장치가 아닙니다.**
> 이 사이트는 서버 없이 파일만 올라가는 방식이라 비밀번호 검사가 브라우저 안에서만 이루어집니다.
> 소스 보기를 하면 비밀번호가 그대로 보입니다.
> '남이 못 고치게 막는 자물쇠' 가 아니라 '실수로 편집 모드에 들어가는 걸 막는 정도' 로 봐주세요.
> 정말 감춰야 하는 값은 `data.js` 에 적지 마세요.

편집 중 아래쪽 막대의 버튼 세 개는 이런 뜻입니다.

| 버튼 | 하는 일 |
|---|---|
| 이 브라우저에 저장 | 지금 이 브라우저에서만 보이도록 임시 저장합니다. 다른 기기·다른 사람에게는 보이지 않습니다. |
| **data.js 내려받기** | 고친 내용이 담긴 `data.js` 파일을 받습니다. **이 파일을 저장소에 덮어써야 모두에게 반영됩니다.** |
| 편집 종료 | 편집을 끝내고 원래 화면으로 돌아갑니다. |

임시 저장된 내용을 보고 있을 때는 화면 맨 위에 안내 띠가 뜨며,
`원래 파일로 되돌리기` 를 누르면 저장소의 `data.js` 내용으로 돌아갑니다.

고칠 수 있는 것은 **글자**입니다. 항목을 새로 추가하거나 삭제하는 것은 `data.js` 를 직접 편집해 주세요.

브라우저에서 인쇄(⌘P / Ctrl+P) → 대상을 **PDF로 저장**.

## 폰트

Pretendard 를 Regular(400) · Medium(500) · Bold(700) 세 굵기로 씁니다.

불러오는 순서는 이렇습니다.

1. CDN (가장 빠르고 다른 사이트와 캐시를 공유)
2. `fonts/*.woff2` — CDN 이 막힌 환경용 (원본 OTF 를 절반 크기로 변환한 파일)
3. `fonts/*.otf` — 아주 오래된 브라우저용

그래서 `fonts` 폴더도 함께 올려야 합니다.

> ⚠️ **굵은 글씨가 안 나올 때**
> `@font-face` 의 `font-weight:700` 블록이 **Bold 파일**을 가리키는지 확인하세요.
> 여기를 Regular 파일로 두면 브라우저가 "이게 볼드다" 라고 믿어버려서
> 보통 굵기 그대로 표시됩니다. (실제로 한 번 겪은 문제입니다)
>
> 중간 굵기(500)는 로컬에 Medium 파일이 없어, CDN 이 막히면 Regular 로 보입니다.
> 필요하면 `Pretendard-Medium.woff2` 를 `fonts` 에 넣고 해당 블록에 경로를 추가하세요.
