# 윤희성 · 포트폴리오 랜딩 페이지

메인 / 이력서 / 자기소개서 / 포트폴리오 4개 페이지를 상단 버튼으로 오가는 한 장짜리 사이트입니다.
처음 열면 메인 화면이 보이고, 잡초가 작은 씨앗에서 자라나는 애니메이션이 재생됩니다.

## 폴더 구성

```
index.html   ← 디자인 + 화면 구조 (평소엔 건드릴 일 없음)
data.js      ← ✏️ 내용은 전부 여기에 있습니다. 이 파일만 고치세요.
fonts/
  Pretendard-Regular.otf
images/
  profile.jpg  ← 프로필 사진을 이 이름으로 넣으세요
README.md
```

## 내용 수정하는 법

1. `data.js` 를 메모장·VS Code·GitHub 웹 편집기 아무거나로 엽니다.
2. 따옴표 `" "` 안의 글자만 바꿉니다.
3. 저장하고 브라우저에서 새로고침하면 끝입니다.

규칙은 세 가지뿐입니다.

- 줄 끝의 쉼표 `,` 는 지우지 않습니다.
- 항목을 늘리려면 `{ ... }` 블록을 통째로 복사해 아래에 붙여넣고 쉼표로 잇습니다.
- 줄바꿈이 필요하면 글자 사이에 `\n` 을 넣습니다.

주요 위치

| 고치고 싶은 것 | `data.js` 안의 항목 |
|---|---|
| 메인 화면 문장 · 버튼 | `main` |
| 프로필 사진 · 한 줄 소개 | `profile` |
| 개인 신상정보 | `personal` |
| 학력 · 경력 | `history` |
| 기술 스택 | `skills` |
| 프로젝트 | `projects` |
| 자격증 | `certificates` |
| 기타사항 | `extras` |
| 자기소개서 (소제목 + 내용) | `cover` |
| 포트폴리오 | `portfolio` |
| 하단 연락처 | `contact` |

## 프로필 사진 넣기

`images` 폴더에 사진을 넣고, `data.js` 의 `photo` 를 그 파일 이름으로 맞춰주세요.

```js
photo: "images/profile.jpg",
```

경로가 비어 있거나 파일이 없으면 따뜻한 그라데이션 카드가 대신 보입니다.

## GitHub Pages 로 올리기

1. GitHub 에서 새 저장소를 만듭니다 (Public).
2. 이 폴더의 **모든 파일**을 그대로 업로드합니다. (`fonts` 폴더 포함)
3. 저장소 → **Settings → Pages** 로 이동합니다.
4. *Source* 를 **Deploy from a branch**, *Branch* 를 **main / (root)** 로 두고 저장합니다.
5. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 으로 접속됩니다.

> 저장소 이름을 `아이디.github.io` 로 만들면 주소가 `https://아이디.github.io/` 로 짧아집니다.

이후에는 GitHub 웹에서 `data.js` 를 직접 수정하고 **Commit changes** 만 눌러도 사이트가 갱신됩니다.

## 메인 화면

가운데 큰 문장, 그 아래 버튼, 그리고 뒤에서 자라나는 잡초 그림으로 이루어져 있습니다.

- 문장과 버튼 글자는 `data.js` 의 `main` 에서 바꿉니다.
- 버튼이 어느 페이지로 갈지는 `main.button.target` 으로 정합니다.
  (`resume` = 이력서 / `cover` = 자기소개서 / `portfolio` = 포트폴리오)
- 잡초 그림은 이미지 파일이 아니라 코드(SVG)로 그려집니다.
  이미지 파일을 챙길 필요가 없고, 어떤 화면에서도 선명하며, 색은 사이트 그라데이션과 같습니다.
- 메인 버튼을 다시 누르면 자라나는 애니메이션이 처음부터 다시 재생됩니다.
- 기기에서 '동작 줄이기'를 켠 사용자에게는 애니메이션 없이 다 자란 모습이 바로 보입니다.

## 페이지 바로가기 주소

- 포트폴리오 : `.../#portfolio`

## PDF 로 저장

브라우저에서 인쇄(⌘P / Ctrl+P) → 대상을 **PDF로 저장**.
인쇄할 때는 상단 버튼·하단 연락 배너·메인 화면이 빠지고,
이력서 · 자기소개서 · 포트폴리오가 이어서 출력됩니다.

## 폰트

Pretendard-Regular 를 사용합니다.
빠른 로딩을 위해 CDN 을 먼저 쓰고, 인터넷이 없거나 CDN 이 막힌 환경에서는
같은 폴더의 `fonts/Pretendard-Regular.otf` 로 자동 대체됩니다.
그래서 `fonts` 폴더도 함께 올려주는 편이 좋습니다.

## iOS · 모바일 대응

- 아이폰 노치 / 홈바 안전영역(`safe-area-inset`) 반영
- 화면 회전 시 글자 크기 튐 방지(`-webkit-text-size-adjust`)
- Safari 용 `-webkit-backdrop-filter` 접두사 적용
- 구형 iOS Safari(15 미만)용 이미지 비율 대체 규칙 포함
- 640px / 900px / 360px 세 단계 반응형
